v0.1.0 · Linux · C++20

The Windows Task Manager look, in your Linux terminal.

wtop is a Task Manager style take on top: one screen per resource, a 60-second braille history graph, a statistics panel, and tmux-style tabs. A single static binary with no ncurses and no third-party runtime dependencies.

$ curl -fsSL https://raw.githubusercontent.com/tomjnet/wtop/HEAD/install.sh | bash

No root, no compiler needed. Installs to ~/.local/bin. Other ways to install →

Download release View source

# Features

⣿⣷⣄

Braille history graphs

Every resource gets a smooth 60-second graph drawn with braille glyphs and 24-bit color, just like the Performance page.

[0:1:2]

Tabs, tmux style

Each screen is a tab. Switch with Ctrl+b then n, p, a number or w for a picker.

▌▌▌

Live resource sidebar

On wide terminals a Task Manager style sidebar lists every CPU, disk, adapter and GPU with a mini live graph.

0 deps

Zero dependencies

Pure C++20 standard library and POSIX. No ncurses. Release binaries are fully static and run on any glibc or musl distro.

GPU

NVIDIA, AMD & Intel GPUs

NVIDIA through nvidia-smi on a background thread; amdgpu, i915 and xe straight from /sys/class/drm.

--snap

Scriptable snapshots

wtop --snapshot prints every tab once as plain text, handy for scripts and bug reports.

# Install

Linux on x86_64 or aarch64. The installer downloads the latest static release binary, verifies its SHA-256 checksum, and falls back to a source build when no binary fits.

# latest release, into ~/.local
curl -fsSL https://raw.githubusercontent.com/tomjnet/wtop/HEAD/install.sh | bash

# a specific version
curl -fsSL https://raw.githubusercontent.com/tomjnet/wtop/HEAD/install.sh | bash -s -- --ref v0.1.0

# make sure ~/.local/bin is on your PATH
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
# read the script before running it (a good habit)
curl -fsSLO https://raw.githubusercontent.com/tomjnet/wtop/HEAD/install.sh
less install.sh
bash install.sh
# Ubuntu 24.04 / Debian 13: GCC 13+ or Clang 17+, CMake 3.20+
sudo apt-get install -y git cmake g++ make

git clone https://github.com/tomjnet/wtop.git
cd wtop
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
ctest --test-dir build --output-on-failure

# user install (no root) or system-wide
cmake --install build --prefix ~/.local --strip
sudo cmake --install build --strip
# checksums and signed build provenance from GitHub Actions
sha256sum -c SHA256SUMS --ignore-missing
gh attestation verify wtop-linux-x86_64.tar.gz -R tomjnet/wtop
curl -fsSL https://raw.githubusercontent.com/tomjnet/wtop/HEAD/install.sh | bash -s -- --uninstall
Installer options
OptionDescription
--prefix DIRInstall under DIR instead of ~/.local
--ref REFRelease tag such as v0.1.0 (default: latest); a branch name builds from source
--binaryOnly install a pre-built binary, never build
--from-sourceAlways clone and build from source
--repo URLGit repository to clone
--source DIRBuild from an existing local checkout
--jobs NParallel build jobs (default: number of CPUs)

--verboseShow the full git, CMake and compiler output

WTOP_PREFIX, WTOP_REF and WTOP_REPO set the same defaults from the environment, WTOP_RELEASES_URL points downloads at a mirror, and CXX picks the compiler to try first.

# Usage

Start it and go. Everything else is optional.

$ wtop --help
wtop [options]

  -d, --delay <ms>       Refresh interval in milliseconds
                         (default 1000, min 100)
  -t, --tab <n>          Tab to open first (0 = CPU, 1 = Memory, ...)
  -s, --snapshot [WxH]   Print every tab once as plain text and exit
  -h, --help             Show help and exit
  -v, --version          Show the version and license and exit

Examples

# refresh twice a second, open on Memory
wtop -d 500 -t 1

# plain-text dump for a bug report
wtop --snapshot 120x40 > wtop.txt

# full manual
man wtop

# Key bindings

Function keys work like htop. Tabs are switched tmux-style: press the prefix Ctrl+b, release, then a command key. While the prefix is pending the status line shows ^B.

htop style

F1
Show / hide key bindings
F10
Quit

tmux style · prefix C-b

n
Next tab
p
Previous tab
← →
Previous / next tab
0…9
Go to tab by number
l
Last used tab
w
Choose a tab from a list (j/k, Enter)
?
Show key bindings
d q
Quit (also Ctrl+c)

# Where the numbers come from

Everything is read directly from the kernel. Nothing is sent anywhere.

ResourceSource
CPU/proc/stat, /proc/cpuinfo, /sys/devices/system/cpu, /proc/loadavg, /proc/uptime
Memory/proc/meminfo
Disk/proc/diskstats, /sys/block, /proc/mounts + statvfs(), /proc/swaps
Network/proc/net/dev, /sys/class/net, getifaddrs(), /proc/net/wireless
GPUnvidia-smi (background thread) or /sys/class/drm for amdgpu / i915 / xe

A few Task Manager fields map to their closest Linux equivalents: Handles becomes the load average, Paged / Non-paged pool become reclaimable / unreclaimable slab, Page file becomes swap, and Committed is Committed_AS against RAM + swap.

Requirements

  • ✓ Linux (reads /proc and /sys)
  • ✓ A terminal with 24-bit color and UTF-8
  • ✓ To build: GCC 13+ or Clang 17+, CMake 3.20+
